    실제 지도 · GPS 사용 순서

    소스의 실제지도-GPS-시작.cmd를 실행한 뒤 실제 지도 메뉴를 여세요. GPS 위치 켜기를 누르고 브라우저의 위치 권한을 직접 허용합니다. 지도에서 목적지를 선택하고 실제 경로 탐색을 누른 다음 GPS 길 안내 시작을 사용하세요.

    상단 목적지 카드를 펼쳐 주소나 장소 이름을 검색하고 결과의 이름·주소를 확인해 선택하세요. Photon 검색 결과를 실제 도로 경로 탐색에 연결합니다. 입력 중에는 검색하지 않습니다. OpenStreetMap 지도와 OSRM 실제 도로 경로를 사용하고, 실시간 교통은 반영하지 않습니다. GPS 좌표와 이동 기록을 앱에 저장하지 않습니다. GPS 하드웨어 수신과 차량 주행은 아직 검증하지 않았습니다.

    네비게이션: 장소 선택 → 경로 찾기 → 길 안내 시작

    우리 집·한빛 오피스·두빛 공원·새빛 병원·중앙역·두빛 미술관 중에서 출발지와 목적지를 선택하세요. 빠른 길과 편안한 길을 비교하고 안내를 시작하면 차량이 실제 가상 도로 연결망을 따라 이동합니다. 다음 회전·남은 거리·예상 시간을 확인하고, 교통 조건을 바꿔 다음 교차점에서 재탐색할 수 있습니다.

    실제 주소 검색과 GPS는 연결하지 않은 PC 가상 도시 시연입니다. 새로고침 후 안내는 일시정지 상태로 복원되며 네비게이션 기록은 운전자별로 저장됩니다. 실수 학습은 아래의 학습 시연에서 확인하세요.

    01

    한 번의 실수를 경험해요

    ‘출구 놓침 시연’을 누르세요. 1배속 기준 약 37초 동안 첫 출구를 놓치고 대체 경로로 연결되는 과정을 봅니다. ‘다음 상황’으로 바로 넘길 수도 있어요.

    02

    실수였는지 직접 확인해요

    도착 후 ‘출구를 놓쳤어요’를 선택하세요. 의도한 경로 변경은 실수로 학습하지 않습니다.

    03

    같은 길을 다시 달려요

    빠른 길을 선택하고 일반 주행을 시작하세요. 한빛 분기점 안내가 300m에서 450m 전으로 앞당겨집니다.

    04

    운전자를 바꿔 비교해요

    오른쪽 위에서 ‘새 운전자’를 선택하세요. 다른 운전자의 기록은 영향을 주지 않습니다. 합류 구간 회피 선호를 남기면 경로 추천도 달라져요.

    시연판에서 확인할 수 있는 것

    학습·가상 도시 메뉴는 차량용 개인화 동작을 확인하는 시연 화면입니다. 실제 지도 메뉴에서는 주소·장소명 검색, 도로 경로 탐색, GPS 연결을 사용할 수 있습니다. 학습은 규칙 기반이며, 가상 도로·시간·경로 부담 점수는 시연용 수치입니다.

    개인화 규칙과 기록 저장 방식

    확인한 출구 놓침마다 안내를 150m 앞당기며 최대 900m까지 조정합니다. 연속 갈림길은 기본 450m부터 안내합니다. 경로 부담은 복잡 구간당 2점, 확인한 놓침당 2점(구간별 최대 4회), 회피 요청당 12점입니다. 교통 지연을 포함한 예상 분 + 0.4 × 부담 점수가 낮은 경로를 추천합니다. 교통 상황은 가상 시나리오이며, 실시간 API 조회 결과는 별도 표시합니다. 이 가중치는 실험으로 검증되지 않은 시연용 가설입니다.

    프로필·메모·최근 50회 시연 기록은 브라우저 내부에 저장합니다. 차량 앱과는 별도입니다. 음성 안내는 브라우저와 운영체제의 한국어 음성을 사용하며 지원 환경에 따라 소리가 나오지 않을 수 있습니다. 마이크 권한을 요청하거나 음성을 수집하지 않습니다.
