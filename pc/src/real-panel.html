      주차 공간은 교통량과 다릅니다

      전국 지도 등록 시설을 검색합니다. 잔여 면수는 데이터를 제공하는 주차장만 확인할 수 있습니다. 교통량만으로 빈자리를 판단하지 않습니다. 현재 교통 데이터는 미연결이며, 현장 상황은 보고값과 달라질 수 있습니다.

      유가 · 주차 정보 연결 상태

      오피넷 최신 보고 유가 · 주차 운영자 잔여 면수: 미연결. 데이터 연결과 검증이 필요합니다.

      주유소 위치와 주차장 위치는 지도 데이터입니다. 최신 보고 가격·잔여 면수가 없으면 추정 수치를 표시하지 않습니다. 서울 등 제공 지역의 주차 데이터 연결을 준비했습니다.

      회전 안내 목록

        지도·GPS 데이터 사용 안내

        검색 버튼·Enter를 누르면 주소·장소 검색어를 Photon에 전송합니다. 검색어와 검색 결과는 앱의 현재 화면 메모리에서만 사용하며 파일에 저장하지 않습니다. 외부 제공자는 요청을 기록할 수 있습니다.

        일반지도 타일은 OpenStreetMap, 위성지도 영상은 EOX에서 가져옵니다. 선택한 지도 종류와 현재 표시 영역만 요청하며 GPS로 이동한 지도 영역도 해당 서비스에 전달됩니다. 위성 영상은 2025년 합성 영상으로 실시간 주차·교통을 보여주지 않습니다. 검색 결과 선택·경로 탐색·재탐색을 직접 누를 때 좌표를 OSRM 서버로 전송합니다. 위치 추적은 기기 안에서 처리하고 앱에 저장하지 않습니다.

        GPS 권한은 사용자가 직접 허용합니다. 노트북에서는 위치 오차가 클 수 있습니다. 다른 화면으로 이동하거나 창을 숨기면 GPS를 중지합니다. 실제 차량용으로 검증하지 않았으며 실시간 교통·도로 통제·안전 운행 정보는 미연결입니다.
